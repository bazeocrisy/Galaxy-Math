# UI redesign — screenshots for owner review

Branch `review/ui-redesign`. **Not deployed:** the live testing site still runs the approved Multiplication 2.0 build.

Each row shows the old UI (left) and the redesign (right) at the same screen size. Desktop (1280) and phone (390) come first for every screen. Other widths (1366, 768, 375, 320) follow in the "All widths" section. Screenshots are full-page, so tall pages are longer than the screen.

The independent auditor's visual review is in [UX-REVIEW.md](UX-REVIEW.md).
